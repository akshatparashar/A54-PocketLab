# A54 PocketLab

A portable Linux, development, networking, IoT and edge-computing laboratory built from an OPPO A54.

## Hardware

- OPPO A54
- Model: CPH2239
- RAM: 4 GB
- Storage: 64 GB
- Android: 11
- ColorOS: 11.1

## Architecture

Android
→ Termux
→ Linux userspace
→ PocketLab services

## Modules

- Core
- Development Server
- Networking
- AI / Computer Vision
- IoT
- Automation
- Monitoring

## Status

Stage 2 — SSH + Linux environment completed.
